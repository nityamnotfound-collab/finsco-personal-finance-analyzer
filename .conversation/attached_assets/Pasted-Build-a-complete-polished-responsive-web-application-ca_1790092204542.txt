5. AI/ML ANALYSIS
--------------------------------------------------

This is the most important academic component.

Implement REAL machine learning functionality using Scikit-learn.

A. EXPENSE CATEGORY CLASSIFICATION

Create an ML model that predicts an expense category from the transaction description.

Use:

TF-IDF Vectorization + Logistic Regression

Example:

"Swiggy dinner"
→ Food

"Uber ride"
→ Transportation

"Amazon headphones"
→ Shopping

"Netflix subscription"
→ Entertainment

Train the model using a small built-in labeled training dataset.

When a CSV is uploaded or a transaction is entered without a category, use the ML model to predict the category.

Show:

- Predicted category
- Confidence/probability where possible

Explain in the UI:

"FinAI uses Natural Language Processing (TF-IDF) and Logistic Regression to classify transaction descriptions."

B. ANOMALY DETECTION

Use Scikit-learn IsolationForest to detect unusual transactions.

Analyze transaction amounts and relevant numerical features.

Display:

- Number of anomalies
- Anomaly percentage
- Table of suspicious/unusual transactions

Example:

"₹18,500 transaction detected as unusual compared with your historical spending."

Clearly label these as statistical anomalies, not fraudulent transactions.

C. SPENDING PATTERN ANALYSIS

Analyze historical transactions and identify:

- Increasing spending
- Decreasing spending
- Highest spending periods
- Recurring categories
- Unusual spending patterns
